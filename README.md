# Trading Bot на Golang

Простой, но хорошо структурированный шаблон трейдинг-бота на Go.  
Главная цель — **быстро и безопасно тестировать свои торговые стратегии**.

> **Кнопки "бабло" нет.** Но есть удобный инструмент, который помогает проверять идеи одну за другой без риска для капитала.

## Возможности

- Поддержка **Binance** (лёгкое добавление Bybit и других)
- Режим **Backtest** (тестирование на истории)
- Режим **Live** (реальная торговля или тестнет)
- Событийная модель через WebSocket
- Уведомления в Telegram
- Логирование всех сделок в JSONL-файл
- Чистая архитектура (легко расширять)

## Структура проекта

```

├── cmd/main.go                 # Точка входа (backtest / live)

│   ├── config/                 # Загрузка config.yaml + .env

│   │   └── mystrategy/         # Пример стратегии
│   ├── execution/              # Исполнение ордеров + логирование
│   ├── notifier/               # Telegram-уведомления
│   ├── backtest/               # Модуль бэктестирования

```

## Быстрый старт

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/KitoKent/go-trading-bot.git
cd go-trading-bot
```

### 2. Установите зависимости

```bash
go mod tidy
```

### 3. Настройте проект

Скопируйте пример конфига:

```bash
cp .env.example .env
```

**Важно:** у тестнет-счетов Binance свои собственные API-ключи.  
Они отличаются от ключей от реального (prod) аккаунта.  


Отредактируйте `.env` (секреты) и `config.yaml` (настройки).

### 4. Запуск

**Backtest** (рекомендуется начинать с него):

```bash
go run cmd/main.go --mode backtest
```

**Live trading** (тестнет или реал):

```bash
go run cmd/main.go --mode live
```

## Как добавить свою стратегию

1. Создайте новую папку в `internal/strategy/`, например `sma_cross`
2. Создайте файл `strategy.go` и реализуйте интерфейс:

```go
type Strategy interface {
    Name() string
    Init(ctx context.Context, symbols []string) error
    OnCandle(ctx context.Context, candle models.Candle) (*models.Signal, error)
    Stop(ctx context.Context) error
}
```

3. Зарегистрируйте стратегию в `internal/strategy/strategy.go`
4. Укажите в `config.yaml`:

```yaml
strategy: sma_cross
```

## Backtesting в этом шаблоне

В проекте есть **базовый Backtester**, который позволяет быстро проверить работоспособность стратегии.

### Что он умеет:
- Запускать вашу стратегию на исторических данных
- Отслеживать Buy/Sell сигналы
- Считать простую статистику (количество сделок, общий PnL)
- Показывать, работает ли логика открытия/закрытия позиций

### Важные ограничения:

**Текущий Backtester — это упрощённая версия.** Он **не претендует** на высокую точность. 

Основные ограничения:
- Не учитывает **комиссии** биржи
- Не учитывает **проскальзывание** (slippage) и spread
- Очень простая логика управления позициями (по умолчанию одна позиция на символ)
- Не моделирует реальное исполнение ордеров
- Не учитывает задержки между сигналом и открытием позиции

## Что не реализовано (и почему)

Эти вещи намеренно не включены, потому что сильно зависят от вашей стратегии:

- Risk Manager (размер позиции, % риска, максимальная просадка)
- Управление позициями (TP/SL, трейлинг, усреднение)
- Сложные индикаторы (TA-Lib или свои)
- Мультистратегийность (запуск нескольких стратегий одновременно)
- Продвинутый Backtester (комиссии, проскальзывание, моделирование ордербука)

Вы можете добавить всё это под свои задачи.
